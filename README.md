# Life App — Study

A course-and-week reading surface for Enlightenment (FW-BA1102) and Moral Philosophy (FW-BA2202), Weeks 1–8. The default screen is Enlightenment Week 1; this is a starting view, not an inferred current academic week.

## User flow

Choose a course/week → see assigned titles and sections → open the saved reading. Hume's Dialogues can be read in the app. Other collected texts open their private Drive files. The weekly sources include Canvas assignment links and saved tutorial preparation where available.

**Still needed** records Armstrong (Moral Week 7) and Caney (Moral Week 8). Those weeks also visibly show the missing reading alongside their saved case studies. See [READINGS-STATUS.md](READINGS-STATUS.md).

Availability and edition fidelity are distinct. Assigned texts, alternative editions, author manuscripts and teaching reprints are labelled. Uncertain references are explained, including the inferred Kant page mapping. No completion or reading-progress status is inferred from file availability. Verification dates are displayed; Drive availability is not polled live. Lectures/videos remain in Canvas, so this is a reading plan rather than an assertion that all examinable course material is collected.

## Development

No third-party dependencies. `npm run build` builds the Worker; `npm test` checks private storage boundaries. `python scripts/prepare-curriculum.py` regenerates `dist/curriculum-data.js` from the verified file inventory and curated assignments. Hume data is generated by `scripts/prepare-hume.py` from the public-domain text.

Existing routes for importing Week 1–2 anthology PDFs remain supported, with direct links to the already-collected Drive copies. Imported PDFs are isolated per authenticated user in R2. Files in Drive are not automatically copied into R2, and opening a file does not change its sharing permissions.

## Privacy and delivery

Licensed reading bytes, credentials and student records are not committed or bundled. The build uses an explicit asset allowlist. Drive links retain Google's access controls. The public-domain Hume text retains its source notice and licence.

Preserve `.openai/hosting.json` and the existing Site identity. The reading API requires Sites-supplied identity headers and must not be exposed directly on a host accepting spoofed identity headers. Writes require same-origin requests; uploads are capped at 12 MB. Existing API tests use an in-memory R2 double.

This work remains on `codex/enlightenment-readings`. Updating this existing app does not publish the changes or merge other Life App features. Live browser rendering and storage need verification before release.
